# 🔮 관상도사 — 3대 고전으로 읽는 AI 실관상 웹앱

사진(즉석 촬영 / 파일 업로드 / 드래그 앤 드롭 / 붙여넣기)에서 **얼굴 랜드마크 478개를 실제로 측정**해서
눈썹·눈·코·입·턱·삼정 비율로 관상을 풀어 주는 웹앱입니다. 결과는 랜덤이 아니라서 **같은 사진은 언제나 같은 결과**가 나옵니다.

## 주요 기능
| 탭 | 내용 |
|---|---|
| 📸 내 관상 | 촬영(3초 카운트다운·얼굴 가이드·전/후면 전환) 또는 업로드 → 스캔 연출 → 결과 |
| 👁️ 부위별 관상 | 클릭형 십이궁 얼굴 지도, 오관(五官), 부위별 유형 사전 |
| 🍀 운세별 관상 | 재물·연애·취업·건강·사업·명예·자식·대인운이 깃드는 자리, 개운 메이크업 팁 |
| 🌏 인물 관상 | 국내 7명 · 해외 7명 관상 리서치(국내/해외 필터), 내 얼굴과 닮은 인물 매칭 |
| 📜 3대 고전 | 마의상법 · 유장상법 · 신상전편 소개, 삼정 개념 |

**결과 화면:** 실측 라인/십이궁 오버레이 사진 · 훅(hook) 첫마디 · 오행 얼굴형 · 종합점수 · 300자 이상 총평 ·
레이더 차트 · 부위별 풀이 7개(각 300자 내외) · 8개 운세 카드(각 450~560자: 풀이 + 고전 + 개운 포인트 + 메이크업 팁) ·
닮은 인물 Top3 · 실측 데이터 · **결과 이미지 저장(1080×1350 PNG)** · 공유 · 텍스트 복사.

## 실행
정적 파일만으로 동작합니다(서버 코드 없음). ES 모듈과 카메라 때문에 `file://` 대신 웹 서버로 열어야 합니다.

```bash
cd gwansang-app
```

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속. 모바일 카메라는 **HTTPS**에서만 동작합니다.

## 배포 (Cloudflare Pages)
이 앱은 서버 코드가 없는 정적 사이트라 **Cloudflare Pages 무료 요금제**(정적 요청·대역폭 무제한)로 운영합니다.
GitHub의 `main` 브랜치에 올리면 자동으로 다시 배포됩니다.

| 설정 | 값 |
|---|---|
| 프로젝트 이름 | `gwansang-dosa` → 기본 주소 `https://gwansang-dosa.pages.dev` |
| 대표 주소 (도메인) | **`https://gwansangdosa.com`** (Cloudflare에서 구매, Custom domains로 연결) |
| Framework preset | None |
| Build command | (비움) |
| Build output directory | (비움) — 저장소 최상위 폴더를 그대로 배포 |

- 캐시 설정은 `_headers` 파일에 있습니다. (`netlify.toml`은 예전 Netlify용)
- 배포 후 `https://gwansangdosa.com/version.json`의 숫자가 `js/app.js`의 `APP_VERSION`과 같은지 확인하세요.
  앱은 이 숫자를 보고 오래 열린 탭도 스스로 새 버전으로 바꿉니다. 고칠 때마다 두 곳(+ `?v=` 번호)을 함께 올립니다.
- 프로젝트 이름이 달라 주소가 바뀌면 `robots.txt`, `sitemap.xml`, 각 HTML의 `canonical` 주소를 함께 바꿉니다.
- 구글 애드센스·서치 콘솔에는 대표 주소 `gwansangdosa.com`으로 등록합니다. (영어판은 나중에 `facefate.com` 예정)

## 광고 넣기
`js/ads.js`의 `ADS_CONFIG`에 AdSense `client`(ca-pub-…)와 슬롯 ID를 넣으면 자동으로 광고가 채워집니다.
비어 있으면 줄무늬 자리표시가 보입니다.

| 슬롯 | 위치 | 크기 |
|---|---|---|
| `top` | 헤더 아래 | 728×90 (모바일 320×100) |
| `infeed` | 결과 총평 아래 · 운세 4번째 뒤 · 결과 하단 · 부위별 탭 | 300×250 반응형 |
| `side` | PC 사이드바(스크롤 고정) | 300×600 |
| `bottom` | 모바일 하단 고정(닫기 버튼 포함) | 320×50 |

## 구조
```
index.html          화면 뼈대(탭 5개, 카메라 모달, 광고 슬롯)
css/style.css       디자인(라이트/다크, 반응형)
js/analyzer.js      MediaPipe Face Landmarker → 22개 관상 지표 측정(기울기 보정, z-점수)
js/reading.js       지표 → 얼굴형·운세 점수·풀이 문장 조합, 인물 매칭
js/content.js       3대 고전 기반 풀이 DB(오관·삼정·십이궁·오행형·운세·메이크업 팁)
js/figures.js       인물 관상 리서치 데이터
js/ads.js           광고 설정
js/app.js           UI·카메라·업로드·오버레이·결과 이미지 생성
vendor/             MediaPipe 엔진과 얼굴 모델(오프라인 동작, 약 23MB)
```

## 측정 방법
1. 두 눈 중심을 수평으로 맞춰 고개 기울기 보정
2. 눈썹 길이/농도/각도, 인당 폭, 눈 크기/눈꼬리/간격, 콧방울 폭/콧대 길이, 입 크기/입꼬리/입술 두께,
   인중, 턱 길이/턱선 폭, 얼굴 세로비, 삼정 비율, 좌우 대칭, 미소 지수를 **얼굴 크기 대비 비율**로 계산
3. `analyzer.js`의 `BASELINE`(평균·표준편차)과 비교해 z-점수 → 큰 편/평균/작은 편 판정
4. 운세마다 관련 부위 가중치로 점수(62~98) 계산 — 낮은 점수도 "숨은 카드"로 기분 좋게 풀이

> `BASELINE` 값은 대략적인 초기값입니다. 실제 사용자 정면 사진이 쌓이면 평균을 다시 내서 조정하면 판정이 더 정확해집니다.

## 참고
- 풀이는 고전의 체계(오관·삼정·십이궁·오행형)를 현대적으로 재해석한 것으로, 원문 직역 인용이 아닙니다.
- 인물 관상은 공개 초상·사진의 널리 알려진 인상을 바탕으로 한 재미용 해석이며, 인물 사진은 넣지 않았습니다(저작권·초상권).
- 사진은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.
